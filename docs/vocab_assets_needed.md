# Vocabulary series — asset checklist

Generated by `tools/audit_vocab_assets.py` — re-run after adding files.


Four states per word:

| state | meaning | action |
|---|---|---|
| **READY** | app has a word clip **and** an image | nothing to do |
| **IMG** | word clip exists, no picture | add `<key>.png` |
| **AUD** | picture exists in the app, no word clip | record `<key>.mp3` |
| **BOTH** | neither | record + draw, or drop the word |

**Filenames** — lowercase, letters/digits only, no spaces or punctuation
(`x-ray` → `xray`, `yo-yo` → `yoyo`).

* audio → `public/audio/words/<key>.mp3`
* images → `public/vocab/<key>.png` (transparent PNG, roughly square, ~700px)
